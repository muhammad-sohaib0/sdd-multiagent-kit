# PHR 001 — Constitution Adoption

- **Phase:** Pre-milestone — constitution (PLAN.md §6, BOOTSTRAP.md §3.4)
- **Input:** PLAN.md §6 starter article set
- **Date:** bootstrap run, session start

## What was requested

Adopt a real constitution for the kit's own build from the starter article set in PLAN.md §6 — not skipped because "it's just the kit building itself."

## What was produced

`outputs/constitution.md` — the seven articles (Standalone-First, Observable Interfaces, Tests Before Implementation, Simplicity by Default, Framework Trust, Real-World Testing, Amendment Process) adopted as-is, with a preamble binding them to this project.

## Decisions

- Adopted the starter set **as-is**, no amendments. The article set in PLAN.md §6 is already written for this exact project (it was written for the kit specifically, unlike a generic template), so editing it at adoption would be churn without justification.
- **No ADR produced.** Article VII's amendment path is the only automatic-ADR trigger (§8.2); adoption without amendment is not a decision meeting the significance test — no real alternatives existed for a build whose own brief fixes these articles.

## Rationale

Constitution adoption must happen before any milestone drafting so that every document produced from this point forward is checked against the fixed principles, and so the milestone-0 history is complete before milestone 1 begins.
